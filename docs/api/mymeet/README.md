# mymeet.ai — рабочий fallback-поставщик

Досье по mymeet.ai. Контракт API — [`API.md`](API.md), оригинал спеки — [`openapi.json`](openapi.json). Speech2Text экономически целевой на масштабе и текущий prod-путь под live-risk; mymeet — рабочий fallback, переключается одной строкой.

Исследование 2026-06-03; цена API получена 2026-06-10.

## Статус: рабочий fallback

mymeet технически полностью закрывает use case, и его **API заведомо боевое** (публичный Swagger, GitHub API-Docs, MCP-сервер); E2E пройден живьём. Сейчас это fallback на случай деградации Speech2Text. ⚠ Важно: для долгого публичного использования mymeet требует снятия п.7.4 (B2B-договор, недели). По экономике на масштабе уступает Speech2Text по двум причинам:

1. **Экономика.** API-тариф за минуты: 1,5 ₽/мин (12 мес) / 2 ₽/мин (6 мес) = 90-120 ₽/ч, линейно без минимума. На целевом масштабе 1000-3000 ч/мес это в **3-7× дороже** флэт-потолка Speech2Text и съедает маржу подписки 1 990 ₽ за 15 часов (§2). Конкурентен только в пилоте с малым объёмом (точка перелома ~70-90 ч/мес).
2. **Юр-риск п.7.4 оферты** — запрет «создания конкурирующего продукта». У mymeet свой `@mymeetaibot` (~$1.3M ARR) — мы прямой конкурент за тех же Telegram-юзеров, поэтому п.7.4 защищает их реальный доход, а не формальность. Без B2B-договора, снимающего п.7.4, публиковать сервис нельзя.

Плюс **слабая диаризация на одноканальном аудио** (тест VC.ru ~70% против заявленных 96-98%) — общий ASR-риск, но у mymeet задокументирован отзывами.

**Плюс mymeet:** саммари даётся **бесплатно из шаблона** (11 шаблонов, обработка на их стороне в РФ) — F3 без OpenRouter и без трансграничной передачи ПДн. По умолчанию F3 в MVP закрывается своим `Summarizer` через OpenRouter, а не шаблоном mymeet; саммари из шаблона снимает трансграничную передачу ПДн — дополнительный плюс mymeet.

**Вердикт по фитнесу: 3/5** — как рабочий fallback годен, по экономике на масштабе уступает S2T, плюс юр-риски п.7.4.

## API (кратко)

Полный контракт — `API.md`. Ключевое (**проверено живым тестом боевым ключом 2026-06-16**): live-join `POST /api/record-meeting` -> `{"meeting_id"}`, **source для Телемоста = `yandextelemost`** (openapi), а НЕ `telemost` (MCP-клиент): `telemost` бэкенд глотает с `200`, но бота не ставит -> вечный `404`; источник истины для `source` — openapi. Поллинг `GET /api/meeting/status` -> **plain-text статус** (не JSON), реально приходит недокументированный **`recording`**, **webhook'ов нет**, свежесозданная встреча сначала даёт `404`; результат `GET /api/video/report` -> транскрипт в `followup_v2.chapters[].transcript[]` (сегмент `{speaker:{...,speaker}, text, timestamp}`; **опровергнут** top-level `result.transcript` из MCP) + саммари из `followup_v2.templates[]` (слайс mymeet-summary, влит 2026-06-18: отдаём вторым файлом, см. `API.md` §1.3); либо `GET /api/storage/download?format=md` -> готовый .md в чат. Удаление — `DELETE /api/video/report` (роута `delete-meeting` нет); программной отмены активной записи нет. Auth `X-API-KEY`. Кастомный промпт саммари не поддержан — только `template_name` из enum.

|---|---|---|
| 6 месяцев | 2 ₽/мин | 120 ₽/час |

- Telemost — только публичный (корпоративный Яндекс 360 не работает); имя бота кастомизируется только на Business.

**Конкуренция (контекст п.7.4):** `@mymeetaibot` — зрелый B2C-продукт в Telegram (~15-30k юзеров, $1.3M ARR, 8 платформ, PDF в чат, AI-чат по встрече). Их API вторичен к ноутейкер-боту, поэтому отдавать его конкуренту структурно невыгодно — отсюда вес п.7.4. (Speech2Text этим не страдает — TG-бот непрофильный.)

## 4. Открытые вопросы (если активируем mymeet)

- **п.7.4:** разрешён ли наш сценарий (оркестратор поверх API), какой договор закрепляет, какой документ регулирует API (оферта vs ToS).
- Фиксация ставки 1,5-2 ₽/мин договором, скидка на объём; безнал ИП/ООО (счёт/акт/УПД/НДС); подъём concurrent-лимита (по умолчанию 2 на аккаунт, `API.md` §5) на B2B/wholesale.
- Техника: остаток после живого E2E 2026-06-16 — форма `failed`/`failure_reason`, диаризация на многоголосом звонке (`API.md` §5; схема `report`, идемпотентность 409, concurrent — уже закрыты).
